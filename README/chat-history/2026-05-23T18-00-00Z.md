## Current Architecture

### Tech Stack
- **Frontend:** Next.js 16.2.6 (App Router, static export), Tailwind CSS v4, TypeScript strict, Jest + React Testing Library
- **Backend:** Fastify, Prisma ORM (MariaDB), JWT auth, Zod validation, Jest
- **Styling:** Zinc-800 dark palette, `#86efac` green accent, glassmorphism, gradient cards, custom scrollbar

### Routes
| Path | Purpose |
|------|---------|
| `/` | Landing page |
| `/login`, `/register`, `/forgot-password`, `/reset-password` | Auth |
| `/dashboard` | Dashboard with stat cards + search |
| `/incidents` | Incident list with table |
| `/incidents/new` | Create incident form |
| `/profile` | User profile (view + password change) |
| `/admin/users` | Admin: create/edit users |
| `/reports` | Reports |

### Data Flow
- Auth: `useAuth` context → `AuthProvider` fetches user via `GET /auth/me` on mount
- Dashboard stats: `GET /reports/summary`
- Incidents: `GET /incidents` with pagination/search/date filters
- Profile: read via `useAuth`, update via `PATCH /auth/users/:id` (admin own profile) or admin users page
- All authenticated requests include JWT from `localStorage`
